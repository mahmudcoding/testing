Параллельные сессии: у каждой свой файл и свой артефакт — `aloqa-<область>-qa-<дата>-<полоса>.html`
(полоса = буква фикстур-лейна, см. CLAUDE.md). Строку в таблицу выше дописывать **один раз, в конце
прогона** — файл общий, и одновременная правка теряет чужую строку.

Сессия запускается одной буквой: `/run-until 14:00 A` = **сектор A на полосе A**
(CLAUDE.md подхватывается сам и отправляет сессию в `SECTORS.md`). Отдельно сектор и полосу
называют только когда они различаются: `/run-until 14:00 sector A on lane C`.

`<область>` закреплена за сектором — см. `SECTORS.md` в корне репозитория. **Сектор** — что сессия
тестирует, **полоса (lane)** — на каких фикстурах и портах она работает; буквы совпадают, но это
разные вещи.

| сектор | область | отчёт |
|---|---|---|
| A · звонки изнутри | `calls-inside` | `aloqa-calls-inside-qa-<дата>-<полоса>.html` |
| B · звонки снаружи | `calls-around` | `aloqa-calls-around-qa-<дата>-<полоса>.html` |
| C · чат | `chat` | `aloqa-chat-qa-<дата>-<полоса>.html` |
| D · организация, доступ, настройки | `org` | `aloqa-org-qa-<дата>-<полоса>.html` |
| E · содержимое воркспейса и оболочка | `workspace` | `aloqa-workspace-qa-<дата>-<полоса>.html` |

Чтобы обновить отчёт из другой сессии, передайте URL как `url` в Artifact —
публикация без `url` создаст отдельный артефакт.
